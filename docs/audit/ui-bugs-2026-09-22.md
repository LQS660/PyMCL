## 与 docs/audit/ 既有结论不符之处

1. `docs/STATUS.md` 记「476 passed / 1 skipped @ 60cc011」已过期；本轮基线实测
   **592 passed / 1 skipped / 90 subtests passed（35s，offscreen）**，收尾全量见 STATUS 更新。

   `import app.*` 的顺序并注释在案，切语言走重启提示，属受控设计取舍。
